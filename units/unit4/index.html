Unit 3 • Fingerprint Analysis

Can a fingerprint identify a person?

In this unit, students learn how friction ridge patterns form, how investigators collect and preserve prints, and how fingerprint evidence can be used to include or exclude suspects. The unit is built around investigation work supported by real lifting and comparison techniques.

Start LabsOpen Unit FilesGuided Notes

Case Briefing

A latent print has been recovered from a key item in the year-long investigation. Students must learn how to classify, lift, and compare fingerprints before they can decide whether the print supports or weakens a suspect link.

Core Vocabulary

TermStudent-Friendly Meaning
FingerprintA print made by friction ridges on the fingers.
Latent fingerprintA hidden print that must be developed to be seen clearly.
Patent fingerprintA visible print left in a substance such as blood, ink, or dirt.
Plastic fingerprintA three-dimensional impression left in a soft material.
MinutiaeSmall ridge details used to compare fingerprints.
Ten cardA full record of a person’s rolled fingerprints.
IAFISA fingerprint identification database system used to compare prints.

Year-Long Case Connection

Case Update: A partial latent print was recovered from a smooth object connected to the scene. Students must determine whether the print is clear enough to compare and whether it is consistent with one of the known suspect prints.

Student Task

Use pattern type, ridge flow, and minutiae to write a short evidence statement. Students should avoid saying “perfect match” unless the evidence supports it. Better wording: “The print is consistent with...” or “The print does not appear consistent with...”

Reliability Discussion

Fingerprints are powerful, but they are not magic. Print quality, partial impressions, human comparison error, and confirmation bias can all affect conclusions.

Prompt 1

What would make a fingerprint comparison stronger?

Prompt 2

What would make a fingerprint comparison weaker?

Prompt 3

How can investigators reduce bias during comparison?
